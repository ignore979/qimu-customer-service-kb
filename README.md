# 栖木家居客服知识库（1组）

「知识库小组作业」项目成果。为模拟客户「栖木家居」的客服人员提供一个可本地运行的知识库网站：输入用户问题，检索《栖木家居客服知识资料》200 页 PDF（2026-10 版），返回带引用依据（QM 主题编号、PDF 页码、资料版本）的回答，并对资料未覆盖的实时状态（订单/库存/物流）与未知能力明确提示「无法确认」，不编造。

## 目录结构

| 目录 | 内容 |
|---|---|
| `01_项目经理/` | 客户资料与需求梳理、项目计划与分工、汇报 PPT |
| `02_产品/` | 用户研究、竞品分析、PRD、知识库测试集、交接说明 |
| `03_开发/` | 开发 A/B 实现与交接、开发与运行说明、项目代码 |
| `04_测试/` | 测试用例与执行结果、问题跟踪与复测 |
| `05_个人贡献说明/` | 五名成员个人贡献说明 |

## 快速开始

见 `03_开发/03_开发与运行说明.md`。核心：在 `03_开发/04_项目代码/` 下运行 `python app.py`，浏览器访问 `http://127.0.0.1:8000`（检索与 JSON 导入零第三方依赖；仅「上传 PDF 直接解析」需 `pip install pymupdf`）。

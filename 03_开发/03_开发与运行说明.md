## 1. 目录与运行

| 文件/目录 | 作用 | 是否为运行必需 |
| --- | --- | --- |
| `app.py` | 网站启动文件（后端 + 静态服务 + 检索/导入接口） | 是 |
| `index.html`、`admin.html` | 检索首页、索引管理页 | 是 |
| `static/style.css`、`static/app.js`、`static/admin.js` | 样式与前端交互 | 是 |
| `knowledge_base.json` | 本地结构化索引（203 个正文主题） | 是 |
| `start.bat` | Windows 一键启动 | 否（便利） |
| `.env.example` | 配置模板 | 否（可选） |
| `requirements.txt` | 可选依赖（pymupdf） | 仅「上传 PDF 解析」时需要 |
| `杜梦涵开发A/` | 开发 A 原始代码（parse_pdf.py 等） | 否（开发记录） |

运行步骤：

1. 准备环境：Python 3.8+（仅标准库即可运行检索与 JSON 导入；如需「上传 PDF 直接解析」再 `pip install pymupdf`）。
2. 配置：复制 `.env.example` 为 `.env` 按需修改（端口、阈值等）；无需任何 API 密钥。
3. 启动：在 `04_项目代码/` 目录运行 `python app.py`（Windows 可双击 `start.bat`）；服务监听 `0.0.0.0:8000`。
4. 执行核心任务：浏览器访问 `http://127.0.0.1:8000`，输入「GB-400 的容量是多少」点击检索，顶部显示简短回答、下方显示 QM-D001/第3页/2026-10 的检索依据。
5. 停止：终端 `Ctrl+C`；错误可查终端输出（索引未就绪会提示去 `/admin` 导入）。

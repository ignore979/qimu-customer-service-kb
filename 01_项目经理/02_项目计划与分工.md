## 1. 项目目标与范围

- **项目目标：** 为栖木家居客服提供本地可运行的知识库问答网站，输入自然语言问题即可定位《客服知识资料》对应内容，返回带引用依据的回答，并对资料未覆盖的内容明确提示无法确认（对应客户目标 C01—C05）。
- **本次包括：** 自由文本问答、来源引用与原文定位、信息不足/实时状态/未知能力的拒答处理、PDF 解析与索引管理、本地运行与局域网访问（对应 PRD 的 F01—F04、F06，即 P0 范围）。
- **暂不包括：** 检索诊断入口 F05、跨型号对比 F07、历史会话 F08 为 P1/P2，首版未纳入必测（见 PRD §1.3）；真实订单/物流/支付 API、生产级权限等 P2 不做。
- **交付与验收方式：** Git 仓库 + 本地运行演示 + 局域网访问；截止日期与提交渠道待教师通知。

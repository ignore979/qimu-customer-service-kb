# 栖木家居客服知识库 —— 运行说明

一个帮助栖木家居客服快速查找《客服知识资料》依据的本地知识库网站。前端为纯 HTML/CSS/JS，后端检索用 **Python 标准库**实现，检索来源为本地结构化索引 `knowledge_base.json`（由《栖木家居客服知识资料》200 页 PDF 解析而来，219 个主题）。

> 依赖说明：**检索与索引管理**零第三方依赖；仅「上传 PDF 直接解析」这一项需要 PyMuPDF（`pip install pymupdf`），不上传 PDF 或改用已解析的 `knowledge_base.json` 上传时无需任何第三方包（详见第八节）。

## 一、目录结构

```text
栖木家居客服/
├── app.py                 # 网站启动文件（后端 + 静态服务 + 检索/导入接口）
├── index.html             # 网站首页（客服检索）
├── admin.html             # 索引管理页（资料导入 / 解析 / 索引状态）
├── knowledge_base.json    # 本地结构化索引（219 个 QM 主题，资料版本 2026-10）
├── static/
│   ├── style.css          # 页面样式
│   ├── app.js             # 检索页交互
│   └── admin.js           # 索引管理页交互
├── .env.example           # 配置模板
├── .env                   # 本地配置（已 gitignore，勿提交）
├── .gitignore
└── README.md              # 本文件
```

## 二、配置

复制 `.env.example` 为 `.env`，按需修改（本地检索无需 API 密钥）：

| 配置项 | 说明 |
| --- | --- |
| `TOP_K` | 每次检索返回的片段条数 |
| `LOW_CONFIDENCE_THRESHOLD` | 相关度阈值，低于该值判定“资料可能未覆盖” |
| `RELEVANT_FLOOR` | 统计“相关内容”条数的明确相关度下限 |
| `MAX_QUESTION_LEN` | 问题长度上限（字符），超出拦截 |
| `KB_VERSION` | 资料版本（随每条结果展示，便于复核） |
| `HOST` / `PORT` | 监听地址与端口 |

> 配置项也可以直接通过同名环境变量传入，环境变量优先于 `.env`。

## 三、启动

环境要求：Python 3.8+（仅标准库）。

方式一（Windows 双击）：直接双击 `start.bat`，会自动启动并打开浏览器。

方式二（命令行）：

```bash
python app.py
```

启动后服务会自动打开浏览器访问 `http://127.0.0.1:8000`；若未弹出，请手动访问：

```text
本机访问：  http://127.0.0.1:8000
索引管理：  http://127.0.0.1:8000/admin
局域网访问：http://<本机局域网IPv4地址>:8000   （监听 0.0.0.0）
```

停止服务：在终端按 `Ctrl+C`（或关闭命令行窗口）。

## 四、局域网访问（作业要求）

- 服务监听 `0.0.0.0`（已默认），供局域网内其他设备访问。
- 查询本机局域网 IPv4 地址：Windows 命令行执行 `ipconfig`，找到 IPv4 地址（形如 `192.168.x.x`）。
- 其他设备访问：`http://<本机局域网IPv4地址>:8000`。

## 五、使用说明

1. 在搜索框输入客服收到的用户问题，点击「检索知识库」或按 `Ctrl+Enter`。
2. 页面顶部先展示「💡 简短回答」（从对应主题的标准字段抽取，不编造），下方为回答依据的检索内容。
3. 每条结果展示：主题编号（`QM-xxx`）、页码、资料版本、相关度与正文内容，可回到原文核对；不展示文件路径。
4. 实时状态 / 未知能力（如订单是否发货、当前库存、连接手机 App 等）会明确提示「无法确认」；未指明型号的保温类问题会先追问并分别给出各型号参数。
5. 与知识库无关的问题（如天气、闲聊、数学等）会明确回答「与本知识库无关」，不强行匹配资料内容；输入超长（>500 字符）、空输入、敏感信息（验证码/密码/令牌）均会被拦截。
6. 「索引管理」页可查看索引状态，并上传 PDF / JSON 重建索引。

## 六、核心实现要点（可核对）

1. **本地结构化索引**：`knowledge_base.json` 每个条目对应一个 `QM-xxx` 主题、真实页码与资料版本，解析为 `{qm, page, title, fields, text}`；过滤封面/目录（页码 ≤2）。
2. **检索打分**（`search_local`）：中文字符二元组召回 + 型号/意图加权 + 字段内容锚点加分，纯标准库实现，可离线复现。
3. **简短回答抽取**（`build_short_answer`）：按问题意图（保温/清洗/组成/规格/漏水/温差/裂纹/售后/物流）抽取对应标准字段（保温性能、清洁与维护、处理说明、客服答复示例等），不编造。
4. **无法确认检测**（`detect_unanswerable`）：对实时订单/物流状态、实时库存、未覆盖功能（App/蓝牙/Wi-Fi/温度曲线）做规则拦截，返回「无法确认」与核验指引。
5. **型号消歧与对比**（`build_model_compare_answer`）：未指明型号的保温类问题先追问并分别给出 BX-500 / BH-1000 参数；多型号对比时分别给出各型号数据。
6. **输入校验**：空输入、超长输入（`MAX_QUESTION_LEN`）、敏感词拦截。
7. **资料导入 / 索引管理**（AC-F04-01~04）：`/admin` 页查看索引状态，`POST /api/import` 上传 PDF（PyMuPDF 解析）或 JSON（标准库解析）并重建索引；失败时给出明确原因。
8. **局域网访问**：监听 `0.0.0.0`。

## 七、接口说明

- `GET /` — 网站首页。
- `GET /admin` — 索引管理页。
- `POST /api/search` — 知识库检索。
  - 请求：`{"question": "用户问题"}`
  - 响应：`status`、`answer`、`insufficient`、`reason`、`total`、`shown`、`results`（含 `qm`、`page`、`version`、`title`、`content`、`score`）、`index` 等。
- `GET /api/index/status` — 索引状态（条目数、主题分布、页码范围、章节）。
- `POST /api/import` — 上传 PDF / JSON 重建索引（`Content-Type: application/octet-stream`，`X-File-Name` 为文件名）。
- `GET /api/health` — 服务健康检查。

## 八、已知限制

- 检索为「字符二元组 + 关键词加权」的规则匹配（非向量语义），对纯口语化改写的召回依赖查询扩展；检索质量受本地索引字段结构影响。
- PDF 解析需要 PyMuPDF（`pip install pymupdf`）；无该依赖时可改用已解析的 `knowledge_base.json` 上传（标准库即可）。
- 资料未覆盖、或需要实时数据（订单/库存/物流状态）与未记录功能的问题，会明确提示无法确认，不编造。
